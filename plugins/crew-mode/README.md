## 세 구역

- **에이전트** — 갈래마다 두 줄: 캐릭터(얼굴) · 이름 · 지금 하는 일(일할 때만, 소품 그림 + 대상) · 걸린 시간, 그 아래 **시간 막대**
  (왼쪽 = 창의 시작, 오른쪽 = 지금). 데스크톱은 막대를 옅은 색 상자로 그려 어떤 글꼴에서도 시각이 맞아요. 도구를 쓴 칸은 조금 진하게,
  일하는 갈래는 빛이 막대를 따라 흐르고 끝(지금)이 숨 쉬듯 깜빡여요. 끝난 자리에 ✓ · ✕. 이름표가 없는 워크플로 에이전트는 `작업자 1, 2 …`.
- **작업** — 제목 줄 오른쪽에 한 마디(커밋 전 3 · 푸시 전 1 · 모두 반영 …)와 `↻`(원격에 다시 묻기).
  - 이 대화의 결과물: 편집 → 커밋 → 푸시 → PR → 머지 를 이은 점. 끝난 단계는 초록 실선, 다음에 할 단계는 주황 점이 숨 쉬고 그 앞으로 빛이 흘러요.
  - 저장소: 한 줄에 이름 · 브랜치 · 좋지 않을 때만 짧은 말 · 세 점(폴더 → 커밋 → 원격). **워크트리**는 `git worktree list` 로 찾아
    본 저장소 아래에 `└` 로 들여 쓰고, Claude 가 만든 워크트리(`.claude/worktrees/…`)에는 `✻` 를 붙여요. 세션이 워크트리 안에서 돌면 본 저장소도 같이 보여요.
- **서버** — usage-bar 와 같은 `▰` 막대: CPU · 메모리(앱 · 시스템 · 압축이 색으로 쌓임) · 스왑(쓸 때만) · 디스크 · 컨테이너 한도.
  값이 바뀌면 막대가 미끄러지듯 따라가고, 데스크톱은 CPU 줄 끝에 지난 1~2분의 흐름(▁▂▅)을 그려요. 제목 줄에 판정(여유 · 빠듯 · 모자람)과 어디서 도는지.

## 명령

```
/crew            창 열기 · 닫기
/crew status     같은 내용을 글자로 대화에 찍기 (/crew 상태 도 돼요)
/crew debug      창이 안 뜰 때 진단
```

첫 턴이 시작되면(데스크톱 화면이 붙어 있을 때) 창이 한 번 저절로 열려요. `/crew` 로 닫으면 다음 세션부터 저절로 열지 않아요(`/crew` 로 다시 열면 원래대로).

## 어디서 그려지나

| 화면 | 모습 |
|---|---|
| 데스크톱 앱 Code 탭 (로컬 · SSH 세션) | 움직이는 창 — Client 모듈 `live-crew.js` · `live-work.js` · `live-server.js` 가 자기 타이머로 |
| 터미널 | 같은 그림, 소품(그림 문자) 없이, 시간 막대는 `━` 글자 |
| 휴대폰 · VS Code | 같은 그림을 멈춘 한 장으로 |
| 원격 제어(`claude remote`)로 붙은 화면 | 창이 그려지지 않아요 → `/crew` 가 글자 요약과 안내를 돌려줘요 |

## 무엇을 하나

- 에이전트: 도구 호출(`tool.call` 의 agentId) · `classic.SubagentStart/Stop` · `$.agent.list()`(1초마다) · `turn.complete`.
- 작업: 성공한 도구의 결과(`classic.PostToolUse`)에서 편집 · 커밋 · 푸시 · PR 을 모으고, 창이 보일 때만 7초마다 `git status` · `git worktree list` ·
  원격 확인(`ls-remote`, 2분 기억) · `gh pr` 을 읽어요.
- 서버: 창이 보일 때만 4초마다 — macOS 는 `vm_stat` · `iostat` · `sysctl` · `ps` · `df`, Linux 는 `/proc` · cgroup.
- 저장: `$.state` 에 이 세션의 에이전트 · 흐름 · 이 대화가 한 일(v: 4, 다시 불러와도 이어져요), `$.store` 에 저절로 열기 선택과 진단.
